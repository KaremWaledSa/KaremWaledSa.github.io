PROJECT CONTEXT

Mobile prototype · Pose analysis

01 / ENGINEERING PROBLEM

What the system needed to do.

Translate a live camera stream into exercise-specific motion feedback while keeping the analysis local to the device.

02 / ENGINEERING APPROACH

How the work comes together.

Camera frames feed Google ML Kit pose detection; body landmarks are converted into joint-angle measurements.

Exercise-specific thresholds, movement states, and cooldowns drive repetition counting and feedback.

The app combines Arabic/English exercise metadata, voice cues, workout state, and settings. The repository includes tests for pose services and application configuration.

03 / RESULT & SCOPE

What the work demonstrates.

A working mobile prototype and public source code. It is an educational fitness tool, not a clinically validated assessment system.

04 / KAREM WALED — RESPONSIBILITY

What I owned and contributed.

  • Implemented the Flutter application structure and camera-driven workout flow.
  • Integrated on-device pose detection and converted landmarks into joint-angle features.
  • Built exercise-specific state logic, repetition counting, cooldowns, bilingual feedback, and voice cues.
  • Added tests around pose services and application configuration.

05 / SYSTEM BREAKDOWN

How the system is structured.

  • Camera frames are processed locally by Google ML Kit pose detection.
  • Landmark coordinates feed angle calculations for exercise-relevant joints.
  • Thresholds and state transitions identify movement phases and completed repetitions.
  • Flutter presents counters, feedback, workout state, exercise metadata, settings, and text-to-speech cues.

06 / TECHNICAL IMPLEMENTATION

Engineering decisions and execution.

01

Geometry

The application calculates joint angles from landmark triplets and uses those measurements as interpretable features.

02

Movement state

Exercise-specific states avoid counting every frame; a repetition requires a valid transition through the expected motion phases.

03

Feedback

Bilingual prompts and optional voice cues turn measured posture conditions into immediate user guidance.
