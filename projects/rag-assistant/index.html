PROJECT CONTEXT

Full-stack prototype · Retrieval & review

01 / ENGINEERING PROBLEM

What the system needed to do.

Help operators respond using approved business knowledge while preserving human control over outgoing customer messages.

02 / ENGINEERING APPROACH

How the work comes together.

An authenticated Express API connects semantic retrieval over PostgreSQL/pgvector with response generation.

A Flutter inbox lets an operator review, edit, or approve the proposed response before the delivery step.

The repository includes mocked unit/integration tests, a React proof of concept, and a Docker Compose development environment.

03 / RESULT & SCOPE

What the work demonstrates.

A functional prototype with source and test infrastructure. Live messaging and AI services require configured external accounts; the website does not claim production deployment.
